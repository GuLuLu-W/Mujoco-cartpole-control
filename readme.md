本项目以一阶倒立摆为控制对象，通过 MuJoCo 完成高精度物理建模与仿真环境搭建；实现传统控制（PID 稳摆、能量法起摆）与强化学习控制（RL 自主起摆、障碍物环境避障）两大核心能力；额外拓展障碍物仿真环境，完成 RL 算法下的倒立摆起摆 + 避障 + 稳摆一体化控制，适用于控制理论学习、强化学习仿真验证、机器人控制算法测试。
核心功能:
1、MuJoCo 一阶倒立摆精准建模
定义摆杆、转轴、质量块、阻尼等物理参数，构建标准一阶倒立摆仿真模型；支持自定义物理参数（质量、长度、摩擦系数等）。
2、传统控制算法
PID 稳摆：闭环 PID 控制，将倒立摆稳定维持在直立平衡状态；
能量法起摆：基于能量控制原理，将摆杆从自然下垂状态快速拉起至直立临界位置。
3、强化学习（RL）控制算法
无障碍环境 RL 起摆：智能体自主学习起摆策略，无需人工调参，完成全自动起摆；
障碍物环境建模：在 MuJoCo 中搭建含静态障碍物的拓展仿真环境；
RL 避障控制：智能体同时完成起摆 + 动态避障 + 稳摆，实现复杂环境下的智能控制。
4、技术栈
MuJoCo（物理建模与动力学仿真）、Python 3.x、Pytorch、RL、PID、LQR、卡尔曼滤波
